FREE PUBLISHING — GITHUB PAGES
------------------------------
1. Create a free GitHub account if needed.
2. Create a new PUBLIC repository, e.g. rsm-balachander-dindigul.
3. Upload EVERYTHING inside this folder (do not upload only the ZIP).
4. Repository > Settings > Pages.
5. Source: "Deploy from a branch".
6. Branch: main, folder: / (root), then Save.
7. GitHub will provide a free URL similar to:
   https://USERNAME.github.io/rsm-balachander-dindigul/

AFTER THE URL IS LIVE
---------------------
1. Replace https://YOUR-DOMAIN/ in sitemap-template.xml with the live base URL.
2. Rename sitemap-template.xml to sitemap.xml.
3. Add this final line to robots.txt:
   Sitemap: YOUR-LIVE-URL/sitemap.xml
4. Add the website URL to the Google Business Profile.
5. Submit the live site in Google Search Console.
6. Keep the SAME name, phone, address and spelling across the website and Google profile.

SEO NOTE
--------
The site is intentionally written naturally. Do not create fake reviews or mass-copy the same review text.
Real customers should describe their actual experience in their own words. A website can improve online
entity signals, but no site can guarantee a #1 position in Google or ChatGPT.
